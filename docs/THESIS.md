# Thesis

**The next decision, not another dashboard.**

Dashboards and chatbots share one assumption: the person does the starting. A dashboard waits for you to go looking. A chatbot waits for you to describe what you want. In a print shop, that means someone opens every incoming file, works out what the customer meant, runs preflight, and fixes the problem by hand.

An AI-native tool should start the work itself. It should do everything that does not need a person, and stop at the first thing that does.

RollCue does this for roll-fed print intake. When a file arrives, it reads the real artwork: geometry, transparency, spot colours, resolution, the order and the notes. It infers the job: stickers, labels, poster or banner. It runs the checks and prepares the fix: a traced cut contour, a resized page, or a polite return notice. The operator sees one card. It shows what RollCue found, the prepared file beside the original, and one approval button.

Three rules keep this trustworthy.

First, **nothing consequential happens without review**. Approval is bound to the exact bytes the operator saw. If anything changes, the old approval is void.

Second, **it is honest about doubt**. When the evidence is thin, the card says so. When it cannot tell two jobs apart, it offers a choice, not a question box.

Third, **being wrong is cheap**. "Not this?" corrects the job in one step, re-prepares the work, and remembers the correction for similar files only.

Measured side by side, a clean sticker job took 9 clicks and 3 form fields in a representative conventional preflight workflow. In RollCue: 2 clicks, no fields.

The interface of the future is not where you ask. It is where the work is already done, waiting for your yes.

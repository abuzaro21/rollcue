# AI disclosure

## In the product

RollCue uses one machine-learned component: a small multinomial logistic regression (36 features, 4 classes, about 150 weights) that infers the job type. It was trained by `scripts/train.ts` in this repository, on synthetic files generated by `dataset/gen.ts`. It runs in-process. **No large language model, no hosted AI service and no external API** is used at runtime. Customer text is never sent anywhere.

Everything else in the product is deterministic code: file inspection, preflight policy, contour tracing, PDF generation and verification.

## In the making

This project was built with AI coding agents, directed by the project owner.

| Tool | Model | Role |
|---|---|---|
| Claude Code | Claude Opus 5.5 (`claude-opus-5-5`) | Lead architect and implementer: wrote the code, tests, evaluation, documents and film script. |
| OpenAI Codex CLI | GPT-6.1 Sol (`gpt-6.1-sol`), read-only sandbox | Independent co-architect and reviewer. It proposed an independent architecture before seeing Claude's. It is assigned reviews of the concept and UX, inference, preflight correctness, approval and execution, recovery, security, and the final diff; which of these have run is recorded in [EXECUTION_STATE.md](EXECUTION_STATE.md), and the findings are in [`reviews/`](reviews/). It wrote no code in this repository. |

How the agents were used:

- Codex's architecture ([reviews/ARCH-B-codex.md](reviews/ARCH-B-codex.md)) was written without access to Claude's ([reviews/ARCH-A-claude.md](reviews/ARCH-A-claude.md)). The differences were resolved in [ARCHITECTURE-DECISIONS.md](ARCHITECTURE-DECISIONS.md).
- Each Codex review was asked to attack the product, including whether it is a dashboard or a hard-coded flow in disguise. Every reproducible finding was recorded, turned into a failing test where possible, fixed, and re-tested. See [`reviews/`](reviews/).
- Codex's approval covers only the code it reviewed. Changes made after its final review are listed in [SUBMISSION.md](SUBMISSION.md).

## Assets

- All sample artwork is synthetic, generated by `dataset/gen.ts`. No customer artwork, private files or proprietary material was used.
- Fonts: Inter, JetBrains Mono and Instrument Serif, all under the SIL Open Font License, bundled from `@fontsource`.
- Film narration: a synthetic voice, Kokoro-82M (Apache-2.0), voice `af_heart`, generated locally from the script in `film/narration.json`. There is no human narrator. Caption timing and a transcript check used OpenAI Whisper (`small.en`, MIT), run locally. Every product shot in the film is a recording of the real app; the pointer drawn on screen and the moved notification toast are film-only overlays. Details: [FILM.md](FILM.md).
